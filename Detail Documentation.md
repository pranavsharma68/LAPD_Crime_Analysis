# LAPD Crime Data Analysis – Full Case Study

## 📊 Project Overview
This project analyzes crime data to identify patterns, trends, and key risk factors across different regions, time periods, and demographics. The objective was to transform raw data into actionable insights and develop an interactive Power BI dashboard to support data-driven decision-making for public safety and resource allocation.

---

## 🎯 Business Problem / Objective
The dataset lacked clear visibility into key performance drivers, including:

- Areas with the highest crime rates  
- Crime distribution across gender and demographics  
- Time-based crime trends and peak periods  
- Most frequently occurring crime categories  

The goal was to uncover meaningful patterns that could support crime prevention strategies, resource planning, and informed decision-making.

---

## 📁 Dataset Description
The dataset contains crime-related information, including:

- **Crime Details:** Type of crime, category  
- **Demographics:** Gender (and other possible attributes)  
- **Location Data:** Areas/regions  
- **Time Fields:** Date, time, year  

The data was initially unstructured and required preprocessing before analysis.

---

## 🧹 Data Cleaning & Processing

### In Excel:
- Removed duplicate records and handled missing values  
- Standardized categorical fields (crime type, gender, area)  
- Structured the dataset for analysis  

### In Python:
- Performed exploratory data analysis (EDA)  
- Identified patterns, distributions, and anomalies  
- Used libraries such as Pandas, Matplotlib, and Seaborn for analysis and visualization  

---

## 🛠 Tools & Technologies
- **Excel** → Initial data cleaning and preprocessing  
- **Python (Pandas, Matplotlib, Seaborn)** → Data analysis and EDA  
- **Power BI** → Dashboard development and visualization  

---

## 🔍 Key Insights
- A small number of areas contribute **~40–50% of total crimes**, indicating strong crime concentration  
- Certain crime categories account for **over 60% of total reported cases**, making them critical focus areas  
- Male victims represent **over 60% of total cases**, showing a significant gender disparity  
- Crime incidents peaked during **2022–2023**, contributing the largest share of total cases  
- **Vermont and Washington** emerged as high-crime regions with the highest concentration of incidents  

---

## 📈 Dashboard Overview (Power BI)
The interactive dashboard includes:

- KPI cards for total crimes and key metrics  
- Area-wise crime distribution  
- Category-wise analysis  
- Gender-based crime insights  
- Interactive filters for dynamic exploration  

The dashboard enables stakeholders to quickly identify patterns and make informed decisions.

---

## 💡 Recommendations
- Allocate more law enforcement resources to high-crime areas  
- Increase surveillance and patrolling during peak crime periods  
- Focus preventive measures on high-frequency crime categories  
- Implement targeted awareness programs based on demographic patterns  
- Use data-driven monitoring for proactive crime prevention
