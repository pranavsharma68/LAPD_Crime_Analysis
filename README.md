# LAPD_Crime_Analysis

## 📊 Overview
This project analyzes crime data to identify patterns, trends, and key risk factors across different regions and demographics. An interactive Power BI dashboard was developed to support data-driven decision-making for public safety.

## 📁 Dataset
The dataset includes:
- Crime details (type, category)
- Demographics (gender)
- Location (areas/regions)
- Time fields (date, year)

## 🧹 Data Cleaning
- Removed duplicates and handled missing values (Excel)
- Standardized categorical fields
- Performed exploratory data analysis using Python (Pandas, Matplotlib, Seaborn)

## 🔍 Key Insights
- A few areas contribute ~40–50% of total crimes (high concentration)
- Certain crime categories account for over 60% of cases
- Male victims represent over 60% of reported incidents
- Crime rates peaked during 2022–2023

## 📈 Dashboard Features
- KPI cards (Total Crimes, Victims, Key Metrics)
- Area-wise crime analysis
- Gender-based crime distribution
- Interactive filters for dynamic exploration

## 🛠 Tools & Technologies
- Excel (Data Cleaning)
- Python (EDA & Analysis)
- Power BI (Dashboard & Visualization)

## 🎯 Business Value
- Identifies high-crime areas for resource allocation
- Highlights key crime patterns and risk factors
- Supports data-driven decision-making in public safety
